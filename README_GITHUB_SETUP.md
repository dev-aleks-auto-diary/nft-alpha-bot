# NFT New Collections Bot — версия для GitHub Actions (работает 24/7 бесплатно)

Эта версия не требует включённого компьютера. GitHub сам запускает
проверку каждые 10 минут по расписанию, используя бесплатный сервис
GitHub Actions.

## Шаг 1. Создать репозиторий

1. Зайди на [github.com](https://github.com), нажми **+** в правом верхнем углу → **New repository**
2. Название — любое, например `nft-alpha-bot`
3. Сделай его **Private** (приватным) — по умолчанию так безопаснее
4. Не отмечай "Add README" — просто нажми **Create repository**

## Шаг 2. Загрузить файлы

На странице только что созданного (пустого) репозитория будет ссылка
**"uploading an existing file"** — нажми на неё.

Перетащи туда ВСЕ файлы из этой папки:
- `main.py`
- `config.py`
- `alchemy_client.py`
- `telegram_notifier.py`
- `requirements.txt`
- папку `.github` целиком (в ней лежит `workflows/poll.yml`) — GitHub
  должен сам подхватить структуру папки при перетаскивании

Внизу нажми **Commit changes**.

## Шаг 3. Добавить секреты (твои ключи)

Это безопасное хранилище — значения никто не увидит, даже ты сам потом
не сможешь их посмотреть повторно (только заменить).

1. В репозитории: **Settings** → в левом меню **Secrets and variables** → **Actions**
2. Жми **New repository secret** и добавь по одному, три штуки:

| Name (точно так, заглавными) | Secret (значение) |
|---|---|
| `TELEGRAM_BOT_TOKEN` | твой токен бота |
| `TELEGRAM_CHAT_ID` | твой chat_id |
| `ALCHEMY_API_KEY` | твой ключ Alchemy |

## Шаг 4. Проверить, что всё работает

1. Перейди во вкладку **Actions** в репозитории
2. Слева увидишь workflow **"NFT New Collections Check"**
3. Нажми на него, справа будет кнопка **Run workflow** — нажми, чтобы запустить вручную прямо сейчас, не дожидаясь расписания
4. Через минуту-две обнови страницу — должен появиться запуск с зелёной галочкой ✅ (если красный крестик ❌ — открой его и посмотри текст ошибки, обычно это неверно вписанный секрет)

Дальше GitHub будет сам запускать проверку каждые 10 минут — уже без
твоего участия и без открытого ноутбука.

## Как остановить или поставить на паузу

- Полностью выключить: **Settings → Actions → General → Disable Actions**
  для этого репозитория
- Временно: вкладка **Actions** → workflow → **... (три точки)** → **Disable workflow**

## Как изменить настройки (например, добавить сеть Base)

Редактируй `config.py` прямо в GitHub (открой файл → карандаш ✏️ сверху
справа → правь → **Commit changes**). Изменения применятся при
следующем запуске, ничего пересобирать не нужно.
